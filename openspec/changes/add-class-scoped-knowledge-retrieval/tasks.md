# Tasks

## 1. 分块数据模型与数据库结构

- [x] 1.1 增加关系型知识分块模型，包含确定性的 chunk_id、知识条目、资料和班级归属、行号范围、正文及内容指纹；通过模型测试验证必填字段、外键、唯一性和班级关联约束
- [x] 1.2 扩展数据库初始化流程，创建分块表及班级、资料和知识条目索引；验证全新 SQLite 数据库能够生成预期结构
- [x] 1.3 增加 FTS5 能力和 trigram 分词器检查，并创建持久化检索虚拟表；验证受支持的运行环境可成功初始化，不受支持的环境会给出明确错误

## 2. 确定性分块与索引维护

- [x] 2.1 实现按行切分、大小受限且带少量重叠的确定性正文分块；通过测试覆盖标题、空行、中文文本、超长单行和重复生成结果一致性
- [x] 2.2 根据来源标识、位置、序号和内容生成稳定的分块标识与内容指纹；验证输入不变时标识不变，内容变化时标识随之更新
- [x] 2.3 实现关系型分块及对应 FTS 记录的事务化插入、替换和删除；验证重复索引后不存在重复或孤立记录
- [x] 2.4 扩展教师上传流程，在现有上传事务中创建分块和 FTS 记录；验证上传成功后内容立即可检索，索引失败时文件和本次数据库记录全部回滚

## 3. 已有条目索引回填

- [x] 3.1 增加管理命令，按确定顺序处理已有知识条目并报告成功数和失败数；验证种子条目能够生成归属正确的分块和索引记录
- [x] 3.2 使回填操作在单个条目范围内原子替换分块和 FTS 记录；通过模拟条目失败验证其原有有效索引状态得到保留，且命令以失败状态结束
- [x] 3.3 使回填操作具有幂等性；验证来源内容不变时连续执行两次会得到等价的分块标识和数量，且不产生重复记录

## 4. 班级范围检索服务

- [x] 4.1 为标准化用户文本实现统一且安全的 FTS 查询构造器；验证标点、引号、空白、中文查询和恶意 FTS 语法不能突破预期查询结构
- [x] 4.2 实现内容分块的相关性排序检索，从登录用户获取 class_id，使用 BM25 排序和确定性次级排序；通过混合班级数据验证不会返回其他班级的内容或元数据
- [x] 4.3 生成命中位置附近的片段，并合并范围大量重叠的相邻结果；验证资料尾部命中时返回相关片段而非固定的正文开头
- [x] 4.4 将每条结果映射为资料标题和 ID、稳定分块 ID、起止行号及受保护的详情和文件 URL；验证每条结果均符合来源响应契约
- [x] 4.5 将索引缺失、损坏或无法使用的故障转换为检索不可用服务错误；验证服务不会回退到未限定范围或结果不完整的查询

## 5. 检索 API 与权限控制

- [x] 5.1 使用现有 API 身份认证保护逻辑增加 GET /api/knowledge/search；验证未登录请求返回 HTTP 401，且不包含正文或来源元数据
- [x] 5.2 校验 q 参数并返回稳定的 JSON 响应；验证空查询返回 400 和 invalid_query，有效但无匹配的查询返回 200 和空 results 数组
- [x] 5.3 忽略客户端提交的班级标识，并将已认证用户传入检索服务；验证通过查询参数、请求正文和请求头选择其他班级均无法改变结果范围
- [x] 5.4 检索索引无法处理有效查询时返回 HTTP 503 和 retrieval_unavailable；验证响应不包含部分结果
- [x] 5.5 保留资料详情和文件接口各自独立的权限校验；验证篡改为跨班资料的结果 URL 会返回 403，且不泄露标题、文件名、正文或其他受保护元数据
