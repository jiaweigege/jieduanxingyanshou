# Proposal

## Why

当前的资料搜索能够匹配标题和完整的知识条目正文，但只返回固定的开头摘要，既无法指出实际命中的内容片段，也无法证明结果来自何处。第四次课程迭代需要增加限定在班级范围内的检索能力，在保持平台现有身份认证和班级边界的同时，返回相关片段及可验证的来源链接。

## What Changes

- 为教师和学生增加需要登录的知识库检索功能，检索范围覆盖其所在班级资料的正文内容。
- 检索范围只能由服务端根据当前登录用户的 `class_id` 确定；客户端提交的班级标识不能扩大检索范围。
- 返回按相关性排序的命中片段，而非固定的正文开头；同时返回来源资料标题和标识、稳定的分块标识、行号范围，以及受班级权限保护的详情和文件链接。
- 用户访问任何来源详情或文件链接时，系统仍须重新执行身份认证和班级权限校验。
- 明确定义未登录请求、空查询、无匹配结果、跨班访问尝试以及检索索引不可用时的稳定 API 行为。
- 为新上传资料创建持久化且关联班级的文本分块和检索索引，并为已有知识条目提供可重复执行的回填流程。
- 扩展现有资料页面，使用户能够查看检索结果并打开结果引用的来源资料。
- 补充本地运行、索引维护、功能验收和课程公开仓库提交准备说明。

## Capabilities

### New Capabilities

- `class-scoped-knowledge-retrieval`：提供需要登录且受班级边界约束的正文检索、相关片段排序、内容溯源、新上传资料索引、已有条目回填及可观察的失败行为。

### Modified Capabilities

- 无。仓库目前没有已归档的主规格；本变更建立在此前 `add-auth-rbac-class-knowledge` 变更已经规划和实现的行为之上，不修改其产物。

## Impact

- 在现有 `materials` 和 `knowledge_entries` 数据之外，新增文本分块和检索索引的持久化数据。
- 在当前 Flask 界面中增加独立的知识检索 API 和检索结果展示区域。
- 扩展上传和初始化流程，使系统能够一致地生成可检索分块，并能够回填已有知识条目。
- 增加身份认证、班级隔离、结果溯源、索引、回填和服务不可用行为的测试。
- 继续使用 Flask、Flask-SQLAlchemy 和 SQLite；本次迭代不需要嵌入模型或外部向量数据库服务。

## Non-Goals

- 对话助手、生成式回答、自动摘要或检索增强生成。
- 作业提交、批改或反馈流程。
- 跨班级或全校范围的检索。
- 在本次实现流程中创建远程仓库或将仓库推送到远程平台。
