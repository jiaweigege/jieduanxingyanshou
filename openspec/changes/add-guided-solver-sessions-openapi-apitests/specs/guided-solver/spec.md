# Spec Delta

## Purpose

为教师提供可维护的班级解题引导规则，并让学生在受班级和会话所有权约束的会话中，先检索本班资料，再流式获得带有可核验出处、避免直接给出最终答案的引导。

## ADDED Requirements

### Requirement: 教师可维护本班解题引导技能
系统 MUST 为每个班级提供至少一条可用的“解题引导”类技能。教师 MUST 能列出、创建、查看和更新本班技能的名称与提示词；学生 MUST 只能读取可用技能，不得修改。提示词不能为空，且系统 MUST 始终施加不可由教师提示词覆盖的“只引导、不直接给最终答案”约束。

#### Scenario: 教师维护技能
- **WHEN** 已认证教师创建或更新本班解题引导技能
- **THEN** 后续本班会话可选择该技能并使用更新后的提示词，同时保留强制引导约束

#### Scenario: 学生修改技能
- **WHEN** 已认证学生调用技能写接口
- **THEN** 系统返回 HTTP 403，且数据库中的技能不变

#### Scenario: 无可用技能
- **WHEN** 新班级尚未配置技能
- **THEN** 系统提供至少一条默认的解题引导技能供本班使用

### Requirement: 学生可创建并拥有解题会话
系统 MUST 允许持有效 Bearer Token 的学生创建会话、列出及读取自己的会话和消息。创建会话 MUST 绑定服务端确定的学生、班级和所选本班技能；客户端传入的用户、角色或班级字段 MUST NOT 改变绑定。教师不得以学生身份创建解题会话。

#### Scenario: 学生创建会话
- **WHEN** 学生选择本班可用技能创建会话
- **THEN** 系统返回 HTTP 201、会话标识和技能信息，并在数据库中保存该学生及班级归属

#### Scenario: 选择跨班或不存在的技能
- **WHEN** 学生选择其他班级或不存在的技能标识
- **THEN** 系统返回相同的 HTTP 404 错误结构，且不创建会话

#### Scenario: 访问他人会话
- **WHEN** 学生读取或发送消息到其他学生的会话，不论对方是否同班
- **THEN** 系统与不存在的会话一样返回 HTTP 404，且不泄露所有权或内容

### Requirement: 会话消息先检索再流式引导
系统 MUST 在接受一条有效学生消息后，先以当前用户的班级检索知识库，再启动模型生成。成功流 MUST 使用明确声明的流式媒体类型，先发送来源元数据，再发送有序内容片段，最后发送完成事件；客户端 MUST 能在完成事件之前看到片段。响应内容 MUST 是解题提示、追问或下一步思路，不得直接给出完整最终答案。模型输入 MUST 将检索正文视为不可信资料，并仅引用本次返回的来源编号。

#### Scenario: 有本班来源
- **WHEN** 学生在自己的会话中发送有效问题且本班检索命中
- **THEN** 系统先发送本班来源事件，再逐段发送引导文本，完成事件包含消息标识和有效的来源引用

#### Scenario: 仅其他班级命中
- **WHEN** 问题只匹配其他班级资料
- **THEN** 系统不调用模型，返回无本班相关资料的完成结果和空来源，且不泄露其他班级数据

#### Scenario: 检索或模型故障
- **WHEN** 检索不可用，或流开始前或开始后模型失败
- **THEN** 系统发送稳定错误码，不将未完成片段标记为成功，且不保存成功的助手消息

### Requirement: 会话记录与引用可核验
系统 MUST 在成功完成后持久化学生问题、完整的助手引导及来源标识；读取历史时 MUST 只返回当前用户有权访问的会话内容。来源详情和文件链接 MUST 在每次访问时重新执行 Bearer 与班级检查。

#### Scenario: 完成后重读会话
- **WHEN** 消息流正常完成且学生重新读取自己的会话
- **THEN** 返回的消息内容和来源标识与完成事件及数据库记录一致

#### Scenario: 访问跨班来源
- **WHEN** 用户访问其他班级资料的详情或文件链接
- **THEN** 系统与不存在的资料一样返回 HTTP 404 和相同错误结构，不泄露资料存在性

### Requirement: 保持现有单次问答和密钥边界
既有 `POST /api/knowledge/answer` MUST 继续提供单次非流式问答。新流式会话 MUST 沿用个人临时智谱 API Key 的请求内使用方式，不得在提示词、数据库、日志、响应或浏览器持久存储中保存密钥。

#### Scenario: 旧接口调用
- **WHEN** 已认证用户按原格式调用单次问答接口
- **THEN** 原有 JSON 响应字段与状态码保持可用

#### Scenario: 不同学生使用各自密钥
- **WHEN** 两名学生各自发起流式回答
- **THEN** 每次上游调用只使用该请求的密钥，任一会话或历史读取均不包含密钥
