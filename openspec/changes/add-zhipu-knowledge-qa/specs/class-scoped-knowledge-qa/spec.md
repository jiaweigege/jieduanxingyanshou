# Spec Delta

## Purpose

定义已登录班级成员使用个人智谱 API Key 基于本班知识库进行单轮 AI 问答的行为，使生成答案严格受检索内容约束、带有可验证来源，并让每位用户的密钥只服务于自己的临时请求。

## ADDED Requirements

### Requirement: 知识问答必须经过身份认证并保持班级边界
系统 MUST 只允许持有有效 Bearer Token 的教师和学生使用知识问答。系统 MUST 从当前数据库用户确定班级，且 MUST NOT 使用客户端提交的用户、角色或班级标识改变检索范围。

#### Scenario: 同班成员提交问题
- **WHEN** 已登录教师或学生提交有效问题
- **THEN** 系统只使用该用户当前数据库班级中的知识分块构造回答

#### Scenario: 未认证请求提交问题
- **WHEN** 客户端没有携带有效 Bearer Token 调用知识问答接口
- **THEN** 系统返回 HTTP 401，且不检索知识、不调用模型、不返回来源内容

#### Scenario: 客户端伪造其他班级
- **WHEN** A 班用户在请求中提交 B 班标识、角色或用户标识
- **THEN** 系统忽略这些覆盖字段，并且回答与来源中不包含 B 班内容或元数据

### Requirement: 问题与个人密钥输入必须具有稳定校验
系统 MUST 接受 JSON 格式的 `question` 和 `api_key` 字符串，分别去除首尾空白后进行处理。缺失、非字符串、空白或超过配置上限的问题 MUST 返回 HTTP 400 和稳定的 `invalid_question` 错误；缺失、非字符串或空白的密钥 MUST 返回 HTTP 400 和稳定的 `invalid_api_key` 错误。任何输入校验失败时系统 MUST NOT 调用模型。

#### Scenario: 有效问题
- **WHEN** 已登录用户提交长度在允许范围内的非空问题和非空个人密钥
- **THEN** 系统使用规范化后的问题执行本班知识检索

#### Scenario: 无效问题
- **WHEN** 问题缺失、类型错误、只包含空白或超过长度上限
- **THEN** 系统返回 HTTP 400 和 `invalid_question`，且不调用智谱 API

#### Scenario: 缺少个人密钥
- **WHEN** `api_key` 缺失、类型错误或只包含空白
- **THEN** 系统返回 HTTP 400 和 `invalid_api_key`，且不调用智谱 API

### Requirement: 回答生成必须先检索且限制上下文
系统 MUST 在调用模型前检索当前用户班级的知识分块，按相关性和确定性次级规则选择最多 4 个来源。发送给模型的上下文 MUST 受配置的总字符数限制，并且 MUST 保留每个来源的服务器生成编号、资料归属和行号。

#### Scenario: 检索到多个相关来源
- **WHEN** 有效问题在当前班级命中超过 4 个知识分块
- **THEN** 系统只将排序最前的 4 个有权来源纳入模型上下文和响应来源

#### Scenario: 来源上下文超过限制
- **WHEN** 选中来源的正文总长度超过配置上限
- **THEN** 系统按确定顺序截断上下文，同时保留来源编号与可核验的来源元数据

#### Scenario: 检索只命中其他班级
- **WHEN** 当前问题只匹配其他班级的知识内容
- **THEN** 系统视为无命中，不调用模型，也不泄露其他班级内容或元数据

### Requirement: 无检索命中时不得调用模型
当前班级没有匹配来源时，系统 MUST 直接返回 HTTP 200、`generated: false`、空 `sources` 和明确的“本班知识库中没有相关资料”提示，且 MUST NOT 向智谱 API 发送请求。

#### Scenario: 本班没有相关资料
- **WHEN** 合法问题在当前班级检索不到任何来源
- **THEN** 系统返回本地无资料提示、`generated: false` 和空来源列表，且模型调用次数为零

### Requirement: 生成回答必须以知识来源为依据
检索命中时，系统 MUST 要求智谱文本模型仅根据提供的来源生成简短中文回答，不得启用联网搜索、工具调用或知识库外部补充。成功响应 MUST 包含 `generated: true`、纯文本 `answer` 和服务器生成的 `sources` 数组；回答中的引用 MUST 只使用与数组顺序一致且实际存在的 `[1]` 至 `[N]` 编号。

#### Scenario: 生成带引用的回答
- **WHEN** 本班检索命中且智谱模型正常返回基于上下文的回答
- **THEN** 系统返回 HTTP 200，回答使用有效编号引用，并返回对应来源数组

#### Scenario: 模型返回越界引用
- **WHEN** 模型回答包含当前来源数组之外的引用编号
- **THEN** 系统不得把该内容作为成功回答返回，并按模型响应异常处理

#### Scenario: 来源内容包含提示注入文本
- **WHEN** 检索来源中包含要求泄露密钥、忽略系统规则或调用外部工具的文本
- **THEN** 系统将其视为不可信资料正文，仍只执行基于来源的回答任务，且不泄露密钥或启用工具

### Requirement: 每个回答来源必须可验证且重新授权
每个来源 MUST 包含编号、资料标题和标识、稳定分块标识、起止行号、正文片段以及受保护的详情和文件入口。用户打开来源时，系统 MUST 重新执行 Bearer 认证和班级权限检查。

#### Scenario: 查看同班回答来源
- **WHEN** 用户打开回答中属于本班的资料详情或文件入口
- **THEN** 系统在认证和班级检查成功后返回来源内容

#### Scenario: 篡改为跨班来源
- **WHEN** A 班用户将来源入口修改为 B 班资料标识
- **THEN** 系统与不存在的资料一样返回 HTTP 404，且不泄露 B 班标题、文件名、正文或其他元数据

### Requirement: 每位用户必须提供自己的临时智谱密钥
系统 MUST 要求每位使用问答的已认证用户输入自己的智谱 API Key。浏览器 MUST 只在当前页面内存中保留输入值，服务端 MUST 只在当前请求处理期间使用该值调用智谱。密钥 MUST NOT 被硬编码到源代码、OpenSpec 产物、服务器配置、容器镜像或前端资源，MUST NOT 写入应用数据库、文件、Cookie、URL、`sessionStorage` 或 `localStorage`，并且 MUST NOT 出现在 HTML 回显、JSON 响应、日志或错误消息中。密钥 MUST NOT 在用户之间共享。

#### Scenario: 用户提交自己的密钥
- **WHEN** 已认证用户提交有检索命中的合法问题和个人密钥
- **THEN** 服务端仅使用该密钥完成当前智谱请求，不保存、回显或提供给其他用户

#### Scenario: 页面生命周期结束
- **WHEN** 用户刷新、退出或关闭问答页面
- **THEN** 浏览器不恢复个人密钥，用户下次使用时必须重新输入

#### Scenario: 两个用户分别问答
- **WHEN** 两个已认证用户各自输入不同的智谱密钥并提交问题
- **THEN** 每个上游请求只使用对应请求提交的密钥，任一用户均无法读取或复用另一用户的密钥

### Requirement: 智谱调用失败必须稳定且不泄露敏感信息
系统 MUST 为智谱调用设置连接和读取超时并禁止无限重试。智谱明确拒绝用户密钥时，系统 MUST 返回 HTTP 422 和稳定的 `provider_auth_failed` 错误；限流、超时、网络错误、其他非成功状态、空响应和畸形响应 MUST 映射为 HTTP 503 与稳定的 `ai_unavailable` 错误。系统 MUST NOT 向客户端转发上游响应正文、请求头、密钥、完整提示词或堆栈信息。

#### Scenario: 智谱请求超时或网络失败
- **WHEN** 智谱 API 在限定时间内没有完成或网络连接失败
- **THEN** 系统返回 HTTP 503 和 `ai_unavailable`，并允许用户稍后重试

#### Scenario: 智谱拒绝密钥或触发限流
- **WHEN** 智谱 API 明确返回密钥鉴权失败
- **THEN** 系统返回 HTTP 422 和 `provider_auth_failed`，且不向客户端暴露上游响应或个人密钥

#### Scenario: 智谱触发限流
- **WHEN** 智谱 API 返回限流响应
- **THEN** 系统返回 HTTP 503 和 `ai_unavailable`，且不向客户端暴露上游响应或个人密钥

#### Scenario: 智谱响应结构异常
- **WHEN** 上游返回空回答、无法解析的结构或不满足引用约束的内容
- **THEN** 系统返回 HTTP 503 和 `ai_unavailable`，且不返回部分生成答案

### Requirement: 问答界面必须安全展示单轮结果
资料页 MUST 提供“知识检索”和“知识问答”切换入口。问答界面 MUST 提供密码型个人 API Key 输入，并展示当前用户问题、生成状态、纯文本回答和编号来源卡片，使用现有认证下载流程打开来源。界面 MUST 不在页面加载时暴露用户数据或密钥，MUST 不将问题、答案或密钥保存到 URL、Cookie、`sessionStorage` 或 `localStorage`，并且刷新页面后不得恢复密钥或历史会话。

#### Scenario: 用户完成一次问答
- **WHEN** 已登录用户在问答标签输入个人密钥、提交问题并收到成功响应
- **THEN** 页面展示问题、带编号引用的回答和可操作的对应来源

#### Scenario: 用户重复提交期间操作
- **WHEN** 一个问答请求仍在处理中
- **THEN** 页面显示加载状态并阻止同一表单重复提交，完成或失败后恢复可操作状态

#### Scenario: 页面刷新
- **WHEN** 用户刷新资料页
- **THEN** 系统不恢复个人密钥、之前的问题或回答，并且不产生新的模型调用
