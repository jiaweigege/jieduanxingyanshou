# Proposal

## Why

现有系统只能返回本班知识库的检索片段，用户仍需自行阅读和归纳。增加基于检索结果的简短 AI 问答，可以在不改变班级隔离和来源核验能力的前提下，让教师和学生更快地从已有资料中获得有依据的回答。

## What Changes

- 在现有资料页增加类似参考图的“知识检索 / 知识问答”切换界面，已登录教师和学生都可以提交单轮问题。
- 每次问答先复用当前用户班级范围内的 SQLite FTS5 检索，选取最多 4 个相关分块，再由服务端调用智谱文本模型生成简短中文回答。
- 回答必须仅依据检索上下文，使用 `[1]`、`[2]` 等编号引用，并随响应返回可核验的资料标题、行号、片段、详情和文件入口。
- 班级内没有检索命中时不调用智谱 API，直接说明知识库中没有相关资料；模型不得联网搜索或补充知识库之外的事实。
- 每位用户在问答页面输入自己的智谱 API Key；Key 只保留在当前页面内存并用于当次页面生命周期内的问答请求，刷新、退出或关闭页面后需要重新输入。
- API Key 不共享、不写入应用数据库或服务器配置，也不进入 URL、Cookie、`sessionStorage`、`localStorage`、HTML、日志或响应；服务端只把它用于当前请求的智谱调用。
- 增加稳定的缺少 Key、Key 无效、检索不可用、智谱限流/超时/响应异常等错误行为，并限制问题、上下文、输出长度和请求超时。
- 本次只提供无持久化的单轮问答，不保存聊天记录，不增加多轮会话、流式输出或模型切换界面。

## Capabilities

### New Capabilities

- `class-scoped-knowledge-qa`：定义经过 Bearer 认证、受班级范围限制、由用户自带智谱 API Key 生成且带可验证来源引用的单轮知识问答，以及临时密钥处理和失败行为。

### Modified Capabilities

- 无。项目尚无已归档的主规格；本能力建立在当前已经实现的 Bearer 认证和班级范围知识检索行为之上。

## Impact

- 新增问答服务和受保护的 `POST /api/knowledge/answer` 接口，复用现有 `search_knowledge`、`KnowledgeChunk`、资料详情和文件权限边界。
- 资料页模板、JavaScript 和样式增加问答标签、密码型 API Key 输入、问题输入、加载/错误状态、回答卡片及来源列表。
- 配置和 README 增加智谱 API 地址、模型、超时、个人 Key 临时使用方式和安全风险说明；`.env.example` 与 Docker Compose 不增加任何智谱密钥配置。
- 增加面向智谱 HTTP API 的服务端客户端依赖或标准库适配，并使用完全模拟的上游响应进行自动化测试；测试套件不得发出真实计费请求。
- 部署环境需要能够访问智谱官方 API；现有资料上传、检索、Bearer 认证、教师权限和班级隔离契约保持不变。
